# Personal Portfolio Website

The UX portfolio of Rutuja Deshpande. It's a single-page site with case studies, built with React, TypeScript and Tailwind CSS.

## What's on the homepage

1. **Work**: case studies for Apple privacy labels (CMU) and Privoce
2. **About**: background and timeline
3. **Skills**: tools, skill groups, and what I'm currently learning
4. **Testimonials**
5. **Footer**: email, LinkedIn, and resume

## Built with

| Area      | Tools |
|-----------|-------|
| Framework | React 19, TypeScript |
| Build     | Vite |
| Styling   | Tailwind CSS v4 |
| Routing   | React Router |
| Fonts     | Source Serif 4 (body), IBM Plex Mono (meta text) |
| Quality   | ESLint, React Compiler |

## Design

The designs were made in Figma, and the site follows them. Colors and design tokens are in `src/index.css`.

## Accessibility

The site aims to meet WCAG AA:
- color contrast that passes AA
- layout that still works at 200% zoom
- full keyboard navigation with visible focus
- semantic HTML, descriptive link text, and alt text on images
